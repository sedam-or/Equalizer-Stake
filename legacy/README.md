# Legacy (v0 — capstone)

`v0-capstone.zip` is the original capstone implementation (FastAPI + Next.js, with an unfinished Go skeleton),
built for a single music school. It is archived as a zip **on purpose**: agents and contributors must not read,
build, or depend on it. Everything v2 needs from it has already been distilled into `spec/`.

- Same content is reachable via git: tag `v0-capstone`, branch `archive/v0-capstone`
  (e.g. `git show v0-capstone:srs/03-billing.md`).
- License: MIT (inside the zip, `LICENSE`) — co-authored capstone code. v2 ports *behaviour*, never code verbatim.
