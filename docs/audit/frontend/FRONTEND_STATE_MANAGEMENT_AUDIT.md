## DATA SYNC ANALYSIS

### Current Flow:
```
Page A adds student → triggerRefresh() → refreshKey++
Page B uses refreshKey → useEffect refetches → data updated
```

### Problem:
Only 3 pages use refreshKey. When data changes on one page, other pages don't know.

### Example Scenarios:

| Scenario | Source Page | Target Page | Sync? |
|----------|-------------|-------------|-------|
| Add student | my-students | schedule | ❌ No |
| Add teacher | teachers | schedule | ❌ No |
| Add session | schedule | my-schedule | ❌ No |
| Verify payment | billing | my-payments | ❌ No |
| Approve registration | registrations | students | ❌ No |

---

## STALE DATA RISKS

### High Risk:
1. **Schedule page** — shows old sessions if added from assign-session
2. **Students page** — shows old list if added from my-students
3. **Teachers page** — shows old list if added from admin
4. **Billing page** — shows old invoices if generated by cron

### Medium Risk:
5. **Notifications** — may miss new notifications
6. **Payments** — may show old payment status

---

## RECOMMENDED FIXES

### P0 — CRITICAL
1. **Add refreshKey to ALL pages that fetch data:**
   - schedule, students, teachers, billing, payments, notifications, my-schedule, my-payments

### P1 — HIGH
2. **Add triggerRefresh() to ALL pages that mutate data:**
   - assign-session, billing, registrations, override, holidays, feedback, ratings

### P2 — MEDIUM
3. **Add auto-refresh on focus:**
   - When user returns to tab, refetch data
   - Use `document.visibilitychange` event

4. **Add polling for critical data:**
   - Notifications: refetch every 30 seconds
   - Schedule: refetch every 5 minutes

5. **Consider global state library:**
   - For complex state: Zustand or React Query
   - For simple state: DashboardContext is sufficient
